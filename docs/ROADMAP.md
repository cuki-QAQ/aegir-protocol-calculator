# 后续方向

以下均为候选工作，不表示已实现，也不承诺时间、性能或结果最优性。优先级可根据实测与维护资源调整。

## 先确认与修复

- 按 [已知问题](KNOWN-ISSUES.md) 修复个体设置保存和交换、额外防御与攻击显示、替补字段传递等缺口。
- 用可复现的游戏对照确认伤害、部署顺序、傀儡/复起、同名限制、叠层时机与即时替补。
- 逐项追溯基准面板与模组数据；补齐素材来源与适用许可记录。
- 恢复可重复的数据生成流程，补充有意义的数值与交互回归。

## 确认后再扩展

- 阵容导入导出与可分享配置，先解决字段保留问题。
- 收录有来源和适用条件的参考摆法，明确实测范围；不能未经搜索证明就标为「最优」。
- 研究按持有阵容搜索摆位，先约定评分与约束，再评估性能；算法输出仍需验证。
- 需要时增加移动端交互和离线体验；当前未作完整手机兼容承诺。

## 分发

当前优先保留静态网页、GitHub Pages与完整zip离线包。只有出现明确桌面需求时，再评估桌面打包；本版本没有exe、安装器、自动更新、账号或后台服务。
