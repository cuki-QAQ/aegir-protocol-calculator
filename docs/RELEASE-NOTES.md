# v13 公开测试版：发布说明

阿戈尔开局吞噬计算器是玩家自制的《明日方舟》卫戍协议辅助网页，可配置站位、朝向、层数、策略与整备区，查看本模型的开局吞噬、倒地、复活或替补结果。

适用数据按原包标注为「卫戍协议·规程」序列Ⅰ（act3autochess/V3_1），快照标注日期2026-11-15。可在线使用；下载并解压完整包后，也可直接用浏览器打开 `index.html`，无需exe或账号。

本次主要统一操作说明、计算口径、资料来源与反馈方式，修正文案矛盾，补充已知限制。计算算法和数值沿用原包，原有24个测试断言通过。

这是公开测试版本，尚未完成全面实战验证：直接扣血、傀儡/复起、同名加层和替补时序仍有假设；部分个体设置在刷新或交换时可能丢失，特质、技能、装备和地图效果未完整模拟。它不模拟完整战斗，也不保证最优摆法。详情请先阅读README和已知问题。

欢迎在Issues按模板反馈。机制差异请附地图、场上/整备区完整配置、策略、层数、预期与实际结果，以及实战截图或视频时间点。
