# 已知问题与待确认事项

适用 v13 文案整理版，整理于2026-11-17。本次未修改计算算法；下列事项不能仅靠文字整理视为已修复。

## 已确认的实现或显示缺口

| 编号 | 问题 | 影响与建议 |
| --- | --- | --- |
| K01 | 存档恢复个体字段不完整 | 刷新后场上未恢复练度、潜能、模组；整备区还丢失额外百分比。计算前逐个检查 |
| K02 | 部分移动/取消/交换丢失字段 | 场上拖到空整备槽、整备区拖到已占用棋盘格、取消来自整备区的部署等路径未完整传递设置；操作后重新检查 |
| K03 | 额外防御输入未使用 | `extraDefPct` 未参与结果或减伤；页面已标为预留 |
| K04 | 替补遗漏额外百分比与后续触发 | 猎人战法替补不带入额外百分比，不重跑完整部署加层和吞噬；复杂替补阵容需核对 |
| K05 | 取消标记不回滚继承或参考叠层 | 不能将关系表或叠层参考当作实际吞噬成功次数 |
| K06 | 攻击列与替补展示不完整 | 无继承时可能只显示基准攻击；细则没有替补完整独立数值行 |
| K07 | 基准面板加工过程需追溯 | 代码把模组平加放在持有乘算前；快照是否已含某些模组属性未逐项复核，不宣称面板全部对齐游戏 |
| K08 | 清空与切图并非完整回收 | 仅尝试放回原整备槽，没有原槽或槽位占用时不回收；返回时字段也不完整。切图前记录阵容 |
| K09 | 历史生成脚本落后于发布数据 | 默认目录不同，且未完整生成12单位、模组选项和地图覆盖；不要直接覆盖当前 `data.js` |
| K10 | 全局参数与旧结果未完全联动 | 修改参数只标记过期；重置休整期不恢复之后修改的全局参数。调整后重新计算 |
| K11 | 特质与地形效果仅部分实现 | 攻速、技力、治疗、敌方效果等未完整模拟；安哲拉击倒叠层、乌尔比安范围攻击加成等未补齐；地形装置不自动计算 |
| K12 | 无完整时间轴与回合历史 | 不模拟部署延迟、技能攻击过程、傀儡20秒回归或跨回合累计次数，也不自动推进下一回合 |
| K13 | 部分摘要数值仅为参数 | 未激活时仍显示 `35 + 层数` 参数，已注明仅激活时生效，不能视为实际加成 |
