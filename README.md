# 阿戈尔 · 开局吞噬计算器

玩家自制的《明日方舟》「卫戍协议」阿戈尔盟约站位与开局吞噬估算工具。配置地图、朝向、层数和整备区后，可查看吞噬标记、参考数值、倒地顺序及复活或替补结果。

**当前状态：v13 公开测试版。** 本工具采用简化模型，尚未完成全面实战验证，适合比较摆位与收集反馈；不模拟完整战斗，也不保证最优摆法。

| 干员 | 10 名阿戈尔干员、魔王，以及 Pith 策略下的盟约·辅助干员 |

## 打开与使用

### 在线

维护者开启 GitHub Pages 后，从仓库的 **Settings → Pages** 获取网页地址。仓库代码页面与可操作网页是两个不同地址。本包尚未绑定实际仓库，也未声称已上线。

### 离线

解压完整项目，保留文件夹结构，用浏览器打开 `index.html`。计算所需脚本与图片均在包内；访问外部参考资料时需要联网。

若浏览器限制本地文件，可以双击 `start.bat`：系统能找到 Python 时启动 `8765` 端口的静态服务，找不到时尝试直接打开页面。关闭服务窗口即可停止服务。使用项目本身不要求安装 Python。

`start.bat` 中原有的 Python 服务没有限制为本机监听。若只在本机使用，可以在项目目录手动运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 [本机页面](http://127.0.0.1:8765/index.html)。

### 基本操作

1. 选择地图、策略、全局持有练度，填写休整期阿戈尔层数。
2. 从干员库拖入棋盘或整备区；单击干员卡查看快照中的基准面板与特质资料。
3. 拖入空棋盘格后，拖中央小菱形到四角，或点击方向箭头，确认朝向；Esc 或「取消」可取消部署。
4. 编辑时单击场上干员可改朝向、切换普通/精锐，或打开「装备」设置练度、潜能、模组和额外百分比。
5. 点击「开始本回合」查看结果。此时棋盘为只读结果视图，单击干员可定位细则；点击「重置休整期」恢复计算前的场上与整备区，再调整和重算。

**普通/精锐是局内形态，持有练度是局外档位，两者不是同一个选项。** 个体练度未覆盖时跟随全局。刷新或部分移动后个体设置可能丢失，计算前请检查。

### 移动、移除与重置

| 操作 | 当前行为 |
| --- | --- |
| 场上拖到空棋盘格 | 重新选朝向；取消时恢复原位置 |
| 场上拖到另一名场上干员 | 双方都能部署到交换后的地块时互换，保留各自朝向；并非一律禁止地面与高台互换 |
| 拖回整备区或与整备区交换 | 留作后备；部分路径不能完整保留个体设置 |
| 干员库拖到已占用位置 | 替换原实例，原实例不会自动补回 |
| 场上红色 ✕、整备区「移除」、拖到干员库 | 删除该实例，不计算出售资金 |
| 切换地图 | 清除场上和结果，保留整备区；仅尝试按原整备槽回收，不保证全部回收 |
| 清空场上 | 清除场上干员，仅尝试按原整备槽回收 |
| 清空阵容与层数 | 清空场上、整备区和结果，层数归零；保留地图、策略、全局练度和新放置形态 |
| 重置休整期 | 恢复最近一次计算前的场上与整备区，不恢复之后修改的全局参数，不推进下一回合 |

## 如何理解结果

- 激活人数按不同阿戈尔名字计数，同名只算 1 名；有调和时合计再加 1，多名调和不重复增加。
- 预估开局层数为本模型在吞噬前使用的层数，不含吞噬标记提供的参考叠层。
- 达到 6 人档后，Pith 与「其他」均按前 3 名阿戈尔倒地原地复活处理；猎人战法改为从整备区右侧取可部署的阿戈尔替补。「其他」不模拟其他具体策略的专属效果。
- 「标记来源 / 标记目标」包含后来取消的标记，不能直接理解为实际吞噬成功次数；同名实例请按位置区分。
- 「标记叠层参考」按全部标记的唯一目标等阶汇总，含取消标记；不回算本次生命，也不自动带入下一回合。
- 特质资料展示不代表效果全部实现。攻速、治疗、技能等未完整模拟；地图地形与装置效果不自动应用，额外防御输入目前不参与结算。

公式与顺序见 [计算口径](docs/CALCULATION.md)，具体缺口见 [已知问题与待确认事项](docs/KNOWN-ISSUES.md)。
